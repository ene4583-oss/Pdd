# Google Sheets 商品成本台账

1. 用有编辑权限的 Google 账号打开目标 Google 表格，进入「扩展程序 → Apps Script」。
2. 将本目录的 `Code.gs` 内容贴到编辑器的脚本文件。新建名为 `Index` 的 HTML 文件，将 `Index.html` 内容贴进去。
3. 保存后，在函数下拉菜单选择 `setup`，点击「运行」并授权 Google Sheets 和 Google Drive。它会创建空白的「网卖商品」工作表，并为照片建立 Drive 文件夹。
4. 点击「部署 → 新建部署 → Web 应用」。执行身份选择「我」，访问权限选择「仅限我」。复制以 `/exec` 结尾的网址，在手机和电脑上用同一 Google 账号打开。
5. 将表格的共享权限设为「受限」，或只分享给需要访问成本资料的人员。Web 应用的权限不会替表格更改共享权限。

打开网站后，点「新增商品」上传照片并填写售价和费用。成本、利润和利润率会即时计算，保存后同步写入表格。照片保存在部署者的 Google Drive。现有工作表不会被导入新商品列表。

所有金额使用马币（RM）。每件商品可设定目标利润率，默认 20%。建议售价会计入平台费，并预留平台费取整的余量。SKU 是可选的内部商品编号。

填写进货总金额和件数，系统会按两位小数计算每件进货成本。升级已有部署时，请更新两个文件、重新运行 setup，再部署新版本。

售价可先留空。每个商品记录一个进货批次，确认后锁定该批金额和数量，补货可另建一条商品。出货可分次录入，系统保存累计件数、实际收入和销售费用。回本按实际收入扣除销售费用后与已确认进货金额比较。已设售价的商品自动按售价乘以出货数量计算收入，未设售价时填写本次销售总收入。每次出货的包装费默认为 RM 0，平台费、卖家运费和其他费用按商品设定计算。
